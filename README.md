# PixelStarter

A simple booking website for website-building services.

## Before publishing
1. Open `index.html` and replace `YOUR-EMAIL@example.com` in the mailto link with the email address where you want booking requests sent.
2. Create a public repository on GitHub and upload `index.html` (and this README).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish and use the site URL shown in Settings → Pages.

The booking form opens the visitor's email app. It does not collect submissions in a database or accept payments.
